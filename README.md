# Synergy Shaking Hands Club

Token-gated membership club dApp.

- **contracts/** Solidity (OpenZeppelin ERC721, soulbound membership NFT, two-step fee flow with admin approval), Foundry tests
- **backend/** Node + Express + MongoDB: wallet-signature auth (JWT), invite codes, applications, interviews, chat (Socket.io), meeting recordings
- **frontend/** Next.js + Tailwind + ethers v6
